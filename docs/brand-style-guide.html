Typography

Шрифтовая пара проекта: Inter для основного текста и Playfair Display для заголовков.

Heading family

Playfair Display

Used in: h1-h6, brand title, hero headings, key UI labels.

Body family

Inter is the default body font for paragraphs, buttons, inputs and general interface text. It keeps the UI clean and readable.
