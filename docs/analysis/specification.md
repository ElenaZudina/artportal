1. Введение
1.1 Цель документа
Настоящее техническое задание (ТЗ) определяет требования к разработке и доработке веб-приложения "Art Portal" — портала для просмотра и управления коллекцией картин художников. Документ основан на анализе текущего состояния проекта и предназначен для завершения разработки, устранения выявленных недостатков и обеспечения готовности к эксплуатации.

1.2 Область применения
ТЗ применяется к доработке существующего PHP-приложения с MVC-архитектурой. Проект включает базу данных, модели, контроллеры, представления и маршрутизацию. ТЗ охватывает функциональные и нефункциональные требования, интерфейсы, данные и тестирование.

1.3 Определения и акронимы
MVC: Model-View-Controller (архитектурный паттерн).

PDO: PHP Data Objects (расширение для работы с базами данных).

CSRF: Cross-Site Request Forgery (атака подделки межсайтовых запросов).

RESTful API: Representational State Transfer Application Programming Interface.

CRUD: Create, Read, Update, Delete (операции с данными).

2. Общее описание
2.1 Перспектива продукта
"Art Portal" — веб-приложение для просмотра галереи картин, фильтрации по стилям и художникам. Текущая версия позволяет отображать коллекцию, но требует доработки для полной функциональности: аутентификации пользователей, загрузки изображений, комментариев и администрирования. Приложение использует MVC-архитектуру с разделением на модели (данные), представления (шаблоны) и контроллеры (логика).

2.2 Функции продукта
Просмотр галереи картин с пагинацией.

Фильтрация картин по стилям и художникам.

Регистрация и аутентификация пользователей (администраторы и обычные пользователи).

Загрузка новых картин (только администраторами).

Добавление комментариев к картинам (аутентифицированными пользователями).

Администрирование: управление пользователями, стилями и картинами.

2.3 Характеристики пользователей
Обычные пользователи: Просмотр галереи, фильтрация, добавление комментариев.

Администраторы: Все права пользователей + загрузка картин, управление контентом.

Гости: Просмотр галереи без взаимодействия.

2.4 Ограничения
Сервер: Apache/Nginx с PHP 7.0+ и MySQL 5.7+.

Браузеры: Современные (Chrome, Firefox, Safari) с поддержкой HTML5/CSS3.

Безопасность: Защита от SQL-инъекций, CSRF, XSS.

Производительность: Обработка до 1000 одновременных пользователей.

2.5 Предположения и зависимости
Доступ к серверу с установленным XAMPP или аналогом.

Наличие изображений в директории public/images/.

Использование Composer для управления зависимостями.

3. Конкретные требования
3.1 Внешние интерфейсные требования
3.1.1 Пользовательский интерфейс
Веб-интерфейс на основе Bootstrap 3.x для адаптивности.

Главная страница: Галерея с миниатюрами картин, фильтры по стилям.

Страница картины: Детали, изображение, комментарии.

Формы: Регистрация, вход, загрузка картин, добавление комментариев.

Навигация: Меню с ссылками на разделы.

3.1.2 Интерфейсы с оборудованием
Загрузка изображений через HTML-формы (максимум 10 МБ на файл, форматы: JPG, PNG).

3.1.3 Интерфейсы с программным обеспечением
База данных: MySQL с PDO для безопасных запросов.

Сессии: PHP-сессии для аутентификации.

AJAX: Для асинхронной загрузки комментариев (jQuery).

3.2 Функциональные требования
3.2.1 Управление галереей
FR1: Отображение списка картин с пагинацией (10 картин на страницу).

FR2: Фильтрация по стилям и художникам.

FR3: Просмотр деталей картины (название, описание, стиль, художник).

3.2.2 Аутентификация и авторизация
FR4: Регистрация пользователей с валидацией email и пароля.

FR5: Вход/выход с проверкой ролей (admin/user).

FR6: Защита страниц от неавторизованного доступа.

3.2.3 Управление контентом
FR7: Загрузка картин администраторами (с метаданными: название, описание, стиль).

FR8: Добавление комментариев аутентифицированными пользователями.

FR9: Администрирование: CRUD для пользователей, стилей, картин.

3.2.4 API (опционально для расширения)
FR10: RESTful API для получения данных о картинах и стилях.
