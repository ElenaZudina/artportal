# Руководство пользователя ArtPortal

## 1. Назначение системы

ArtPortal - это учебный веб-портал для публикации и просмотра произведений искусства. Система позволяет посетителям знакомиться с картинами, художниками и выставками, зарегистрированным пользователям - сохранять понравившиеся работы и отправлять заявки на покупку, художникам - вести профиль и управлять своими картинами, а администратору - модерировать пользователей и справочники портала.

Руководство описывает основные действия пользователей без технических подробностей развертывания и настройки системы.

## 2. Роли пользователей

В системе предусмотрены четыре основных типа пользователей:

- Гость - неавторизованный посетитель сайта. Может просматривать публичные страницы, искать картины и художников, открывать выставки, регистрироваться и входить в систему.
- Пользователь - зарегистрированный посетитель. Может пользоваться личным кабинетом, добавлять картины в избранное и отправлять заявки на покупку.
- Художник - пользователь, который заполнил профиль художника. Может публиковать и редактировать свои картины, просматривать заявки на покупку своих работ.
- Администратор - пользователь с расширенными правами. Управляет пользователями, категориями, коллекциями, выставками и модерирует профили художников.

> Место для скриншота: главная страница портала с верхним меню.

## 3. Общая навигация

Основная навигация выполняется через верхнее меню сайта, карточки картин, карточки художников и кнопки на страницах. После входа в систему пользователь переходит в личный кабинет, а администратор - в административную панель.

Публичная часть портала включает:

- главную страницу с подборками и выставками;
- каталог картин;
- список художников;
- страницы отдельных картин и художников;
- список выставок;
- формы регистрации, входа и восстановления доступа.

Для выхода из учетной записи используется кнопка `Logout`, доступная как в личном кабинете или административной панели, так и в меню публичной части.

## 4. Работа гостя

### 4.1. Просмотр главной страницы

Гость открывает главную страницу портала и видит основные разделы: текущую выставку, подборку художников и коллекцию картин. С главной страницы можно перейти к полному списку картин и художников.

> Место для скриншота: главная страница с блоками выставки, художников и галереи.

### 4.2. Просмотр и поиск картин

Чтобы найти картину, гость открывает раздел `All paintings`. На странице отображается список работ с изображением, названием и краткой информацией. При необходимости можно воспользоваться строкой поиска или перейти по категориям.

Для просмотра подробностей нужно нажать на карточку картины. На странице картины отображаются изображение, название, описание, художник, категория и другая информация о работе.

> Место для скриншота: каталог картин.
>
> Место для скриншота: страница одной картины.

### 4.3. Просмотр художников

В разделе `Artists` гость видит список художников. Для перехода к профилю нужно выбрать интересующего автора. В профиле отображается информация о художнике и его опубликованные работы.

> Место для скриншота: список художников.
>
> Место для скриншота: профиль художника.

### 4.4. Регистрация и вход

Для создания учетной записи гость открывает форму `Register`, вводит имя пользователя, email, пароль и подтверждение пароля. После успешной регистрации пользователь может войти в систему.

Для входа используется форма `Login`: пользователь вводит email и пароль. Если данные корректны и учетная запись активна, система открывает личный кабинет.

> Место для скриншота: форма регистрации.
>
> Место для скриншота: форма входа.

## 5. Работа зарегистрированного пользователя

### 5.1. Личный кабинет

После входа пользователь попадает в личный кабинет. На стартовой странице отображается краткая информация: избранные картины, заявки на покупку и быстрые ссылки для перехода к основным действиям.

> Место для скриншота: стартовая страница личного кабинета пользователя.

### 5.2. Изменение данных аккаунта

Пользователь может открыть раздел `View Account`, чтобы посмотреть данные учетной записи. Для изменения имени пользователя или email используется раздел `Edit Email / Username`. После заполнения формы нужно нажать `Save`.

Для смены пароля пользователь открывает раздел `Change Password`, вводит текущий пароль, новый пароль и подтверждение, затем нажимает `Update password`.

> Место для скриншота: страница аккаунта.
>
> Место для скриншота: форма смены пароля.

### 5.3. Добавление картины в избранное

Пользователь открывает страницу картины и нажимает кнопку добавления в избранное. После этого работа появляется в разделе `My Favorites` личного кабинета.

Чтобы удалить картину из избранного, пользователь открывает `My Favorites` и нажимает кнопку удаления у нужной работы.

> Место для скриншота: кнопка добавления в избранное на странице картины.
>
> Место для скриншота: раздел My Favorites.

### 5.4. Отправка заявки на покупку

Если пользователь хочет приобрести картину, он открывает страницу работы и отправляет заявку на покупку. После отправки заявка сохраняется в системе и становится доступна художнику, которому принадлежит картина.

Свои отправленные заявки пользователь может просмотреть в разделе `My Requests`.

> Место для скриншота: кнопка или форма заявки на покупку.
>
> Место для скриншота: раздел My Requests.

### 5.5. Восстановление доступа

Если пользователь забыл пароль, он открывает форму `Forgot password`, вводит email и отправляет запрос. Система передает запрос администратору, после чего администратор может связаться с пользователем и помочь восстановить доступ.

> Место для скриншота: форма Forgot password.

## 6. Работа художника

### 6.1. Создание профиля художника

Зарегистрированный пользователь может стать художником, заполнив форму `Artist Profile`. В форме указываются имя художника, биография, изображение профиля и другая информация. После отправки профиль получает статус ожидания модерации.

До одобрения администратором профиль и картины художника могут быть недоступны в публичной части портала.

> Место для скриншота: форма профиля художника.

### 6.2. Управление профилем

После создания профиля художник может открыть раздел `View Profile`, чтобы просмотреть свои данные, или `Edit Profile`, чтобы обновить информацию. После изменения данных нужно сохранить форму.

> Место для скриншота: профиль художника в личном кабинете.

### 6.3. Добавление картины

Для публикации новой работы художник открывает раздел `My Paintings` и нажимает `Add Painting`. В форме нужно указать название, описание, изображение, категорию, материал, размер и цену. После сохранения картина добавляется в список работ художника.

Краткий порядок действий:

1. Открыть `My Paintings`.
2. Нажать `Add Painting`.
3. Заполнить поля формы.
4. Загрузить изображение.
5. Нажать `Save`.

> Место для скриншота: список My Paintings.
>
> Место для скриншота: форма Add Painting.

### 6.4. Редактирование и удаление картины

В разделе `My Paintings` рядом с каждой картиной доступны действия `Edit` и `Delete`. При редактировании художник изменяет данные работы и сохраняет форму. При удалении система показывает страницу подтверждения, после чего картина удаляется из списка.

> Место для скриншота: кнопки Edit и Delete в списке картин художника.

### 6.5. Просмотр заявок на покупку

Если пользователи отправили заявки на картины художника, они отображаются в разделе `Purchase Requests`. Художник видит информацию о работе и пользователе, который заинтересовался покупкой.

> Место для скриншота: раздел Purchase Requests.

### 6.6. Калькулятор цены

В кабинете художника доступен калькулятор цены. Он помогает рассчитать стоимость работы с учетом желаемого дохода, комиссии и налогового статуса. Художник вводит исходные значения и получает расчет итоговой цены.

> Место для скриншота: модальное окно или блок калькулятора цены.

## 7. Работа администратора

### 7.1. Административная панель

После входа администратор попадает в административную панель. На стартовой странице отображаются показатели системы: количество пользователей, художников, категорий, коллекций и выставок.

> Место для скриншота: стартовая страница административной панели.

### 7.2. Управление пользователями

В разделе `Users` администратор видит список учетных записей. Для быстрого поиска можно использовать строку поиска. Администратор может заблокировать или разблокировать обычного пользователя.

Порядок блокировки:

1. Открыть раздел `Users`.
2. Найти нужного пользователя.
3. Нажать `Block`.
4. Убедиться, что статус пользователя изменился.

Заблокированный пользователь не сможет войти в систему до разблокировки.

> Место для скриншота: список пользователей в административной панели.

### 7.3. Модерация художников

Новые профили художников попадают в раздел `Approve artist profiles`. Администратор открывает заявку, просматривает данные профиля и принимает решение: одобрить или отклонить.

Если профиль одобрен, художник и его работы могут отображаться в публичной части портала. Если профиль отклонен, он не публикуется.

> Место для скриншота: список заявок художников.
>
> Место для скриншота: страница просмотра заявки художника.

### 7.4. Управление категориями

В разделе `Categories` администратор может создавать, редактировать и удалять категории картин. Категории используются для группировки работ в публичном каталоге.

Основные действия:

- `Add category` - создание новой категории;
- `Edit` - изменение названия или описания;
- `Delete` - удаление категории.

> Место для скриншота: список категорий.

### 7.5. Управление коллекциями

В разделе `Collections` администратор управляет подборками произведений. Коллекция может использоваться при создании выставки или для логической группировки работ.

Администратор может добавить новую коллекцию, изменить существующую или удалить ненужную.

> Место для скриншота: список коллекций.

### 7.6. Управление выставками

В разделе `Exhibitions` администратор создает и редактирует выставки. При создании выставки указываются название, описание, даты и связанная коллекция.

Порядок создания выставки:

1. Открыть `Exhibitions`.
2. Нажать кнопку добавления выставки.
3. Заполнить данные выставки.
4. Выбрать коллекцию.
5. Сохранить форму.

> Место для скриншота: список выставок.
>
> Место для скриншота: форма создания выставки.

## 8. Рекомендуемый набор скриншотов

Чтобы не перегружать выпускную работу, достаточно 10-12 иллюстраций:

1. Главная страница портала.
2. Каталог картин.
3. Страница одной картины.
4. Список художников или профиль художника.
5. Форма регистрации или входа.
6. Личный кабинет пользователя.
7. Раздел избранного.
8. Форма профиля художника.
9. Раздел My Paintings.
10. Административная панель.
11. Список пользователей.
12. Модерация профиля художника или управление выставками.

Если объем записки нужно сократить, можно оставить по одному скриншоту на каждую роль: гость, пользователь, художник и администратор.

## 9. Ограничения учебной версии

Так как проект является учебной работой, часть процессов упрощена. Например, восстановление пароля выполняется через обращение к администратору, а некоторые административные действия представлены базовыми CRUD-операциями. Несмотря на это, портал демонстрирует основные сценарии работы реальной системы: регистрацию, авторизацию, личный кабинет, публикацию контента, модерацию и администрирование.
